# 三子棋（Tic-tac-toe）

C 语言课程练习：控制台三子棋，玩家对战电脑（电脑随机落子）。

## 文件

| 文件 | 作用 |
| --- | --- |
| `三子棋game.h` | 常量与函数声明（`ROW`/`COL` 均为 3） |
| `三子棋game.c` | 棋盘初始化、打印、玩家/电脑落子、胜负判断 |
| `三子棋test.c` | 入口 `main` 与菜单，控制一局游戏流程 |

## 玩法

- 棋盘 3×3，玩家执 `*` 先手，电脑执 `#`。
- 玩家按 `行 列` 输入坐标（1~3），落在已有棋子的位置会提示重新输入。
- 电脑在空位里随机选一格。
- 每步之后判断行、列、两条对角线是否三连。

## 胜负返回值

`win()` 用字符表示状态：

| 返回值 | 含义 |
| --- | --- |
| `*` | 玩家胜 |
| `#` | 电脑胜 |
| `f` | 平局（棋盘已满） |
| `c` | 继续 |

## 编译运行

```bat
cl 三子棋game.c 三子棋test.c
三子棋test.exe
```

头文件里已定义 `_CRT_SECURE_NO_WARNINGS`，MSVC 编译无需额外参数。

源码是 **GBK（代码页 936）** 编码，用 MSVC 直接编译正常；gcc/MinGW 建议加 `-fexec-charset=GBK` 或先转 UTF-8，否则控制台中文可能乱码。
